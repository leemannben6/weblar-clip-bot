Privacy Policy

Last updated: November 18, 2026

Who we are

Weblar Clip Bot (“the tool”) is a personal desktop application run by one independent operator in Switzerland. It is only used with the operator's own accounts. Contact: weblar.schweiz@gmail.com.

What data the tool uses

  • Twitch: public chat messages are counted (not stored) to detect highlight moments. An OAuth token with the clips:edit scope is used to create clips.
  • YouTube API Services: with the operator's consent (OAuth), the tool uploads videos to the operator's own channel and reads basic channel and video statistics (views, likes, comments) of those uploads.
  • TikTok: with the operator's consent (Login Kit), the tool reads basic profile information (display name, avatar, follower and video counts), publishes videos to the operator's own TikTok account, and reads view statistics of the operator's own videos.

The tool does not collect data about other people, does not use cookies or tracking, and does not sell or share any data with third parties.

How data is stored

Access tokens and video statistics are stored only locally on the operator's computer. No data is uploaded to any server other than the official YouTube, TikTok and Twitch APIs.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Deleting data and revoking access

  • Google/YouTube access can be revoked at any time at Google security settings.
  • TikTok access can be revoked in the TikTok app under Settings → Security → Apps and services.
  • Twitch access can be revoked at Twitch connections.
  • All locally stored tokens and statistics are deleted when the tool's folder is deleted, or on request via the contact e-mail. Stored API data is refreshed or deleted at least every 30 days.
